# Basic HTML Website

This workspace contains a simple, semantic HTML-only website with multiple pages required by the project:

- `index.html` — Homepage with hero, projects, work, education, and reviews sections.
- `projects.html` — Projects listing.
- `articles.html` — Articles listing.
- `contact.html` — Contact page with a form (name, email, message).

How to view:

1. Open the files in your browser (double-click `index.html`), or serve the folder with a static server.

No CSS or JavaScript is included — this repository focuses on HTML structure only.
